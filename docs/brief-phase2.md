## 1. 音效升级：换成真实的开源音效素材

用户反馈：**现在的合成音效太重复**，听几下就腻。

- 去找**可以直接商用、不需要署名或只需简单署名**的开源音效库，下载到 `assets/sfx/` 本地托管。首选 CC0：
  - Kenney 的音效包（kenney.nl，CC0）：UI Audio、Interface Sounds、Impact Sounds、Digital Audio 等
  - 其他 CC0 来源也可以，比如 freesound.org 上标为 CC0 的素材
  - 不要用需要付费、需要登录才能下载、或者许可不清楚的素材
- 在 `assets/sfx/LICENSES.md` 里记下每个文件的来源网址和许可
- **防重复**：同一个动作准备 2～4 个变体随机播放，每次再加一点随机的音高（±5%）和音量变化。连点同一个按钮时不能听起来像复读机
- 格式用 `.ogg` 或 `.mp3`，单个文件尽量小（几十 KB），总量控制在 2MB 以内
- 合成音效可以保留做“层”（比如长按充能那个上升的音），但主体换成真实素材
- 所有展品（包括第一期已有的 14 件）都要过一遍，换上合适的音效

## 2. 新增三个展厅

### Hall 04 滚动 Scroll
- **视差 Parallax**：多层画面随滚动以不同速度移动
- **钉住滚动 Pinned Scroll**：一段内容钉在屏幕上，滚动时画面在原地变化（讲故事式）
- **横向滚动 Horizontal Scroll**：纵向滚动驱动一条横向长卷
- **滚动进度揭示 Scroll Reveal**：元素随滚动进度逐步出现、遮罩擦开
- **滚动速度形变 Scroll Velocity Skew**：滚得越快，画面越倾斜或拉伸

### Hall 05 转场 Transition
- **FLIP 布局动画**：列表重新排序、卡片展开时平滑地挪到新位置
- **共享元素转场 Shared Element**：点一张小卡片，它“飞”成一个大详情页
- **幕布转场 Curtain / Wipe**：用斜切色块或条纹盖住画面再揭开，像游戏切场景
- **View Transitions API**：浏览器原生的页面切换动画（不支持的浏览器要有降级）

### Hall 06 着色器 Shader（最难，花最多心思）
- **图片扭曲 Hover Distortion**：鼠标经过图片时像水波、像液体一样扭曲
- **位移溶解 Displacement Transition**：两张图之间用噪声图做溶解切换
- **流动渐变背景 Noise Gradient**：三色在背景里缓慢流动
- **粒子成形 Particles to Shape**：粒子聚合成文字或图形，鼠标一碰就散开

着色器展品要有降级：手机或不支持 WebGL 时显示静态画面并提示。注意性能，不在视口内的画布要暂停渲染。

## 3. 给已有展厅多加例子

用户想要更多例子。每个已有展厅再加 2～3 件，挑**最常见、最有代表性**的，例如：

- 按钮：3D 倾斜卡片 Tilt、开关切换 Toggle、提交状态按钮（加载 → 成功）、粘滞融合 Gooey
- 光标：自定义光标 Custom Cursor（混合模式反色）、光标跟随墨迹 Cursor Trail
- 文字：可变字重波浪 Variable Font Wave、文字遮罩填充 Text Mask Reveal、打字机 Typewriter

全部展品做完后，**更新收藏页**（六个展厅全部开放，显示每个展厅的件数），顶部导航也要加上新展厅。

## 4. 素材

需要图片时用你的图像生成能力，统一画风：都市潮流、三色（米白、安全橙、黑），或者沿用 `assets/web/` 那组暗调摄影风。可以给导览员生成新的姿势用在新展厅的标题区（形象设定见第一期说明书），用 `tools/cutout.py` 抠图。图片压缩成 JPG/WebP，单张不超过 300KB。

## 5. 技术

- 可以用 GSAP + ScrollTrigger（现在完全免费）、three.js、ogl 等成熟的库，**全部下载到 `assets/vendor/` 本地托管**
- 仍然不要构建步骤
- 页面变长以后注意首屏加载速度：展厅的脚本和素材在滚动到附近时再加载（懒加载）
