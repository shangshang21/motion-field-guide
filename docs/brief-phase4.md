## 1. 新展厅 Hall 08 手势 Gesture（采纳你的提议 1）

拖、甩、停、撞，让“摩擦”“重量”“回弹”变成能亲手比较的词：

- **惯性拖拽 Inertia Drag**：把卡片甩出去，它带着速度滑行再慢慢停下（参数：摩擦、质量）
- **边界回弹 Rubber Band**：拖过边界时越拉越费劲，松手弹回（iOS 那种手感）
- **滑卡 Swipe Cards**：左右甩走一叠卡片，像交友软件，甩得够快才飞走、不够快会弹回
- **下拉刷新 Pull to Refresh**：往下拉，指示器跟着变形，拉够了松手触发

全部要**手机优先**：用户主要用手机看这个网站。用 Pointer Events，同时支持鼠标和触屏。

## 2. 同屏 A/B 手感对比（采纳提议 2）

给每件可调参的展品加一个 **A/B 按钮**：把当前参数存成 A，继续调出 B，然后两组**并排或叠在一起同时播放**。口令里同时带上 A 和 B 两组参数。用户就能说出“我要 B 那样，再弹一点”。不必每件都做成完全一样的界面，但交互方式要统一、好发现。

## 3. 慢放与逐帧（采纳提议 3）

把右上角的全局速度档扩展成一个小的**播放控制台**：暂停、0.1x 慢放、逐帧前进。利用统一调度器，让页面上所有动效（包括爆炸、弹簧、粒子）都能被冻住和逐帧推进。这样爆炸的“蓄力、定格、冲击波、碎片下坠”每个阶段都能停下来看。

## 4. 分享链接 + 最小代码片段（采纳提议 4）

- 每件展品可以生成一个**分享链接**（把展品和参数编码进 URL 的 query string），打开链接直接跳到那件展品、参数已经恢复
- 对话框里加一个“**拿走代码**”：给出这件展品在当前参数下的**最小可运行实现**（纯 HTML/CSS/JS，能直接粘到别的项目里跑），复制即用

## 5. 导览员的表情（美术总监加的）

现在导览员只有一张半身像。给她生成 **4～6 种表情/姿势**（得意、惊讶、认真讲解、眨眼比耶、捂耳朵（爆炸时）、慢放时打哈欠之类），在不同展厅和不同事件时切换。形象设定见第一期说明书，纯白背景生成后用 `tools/cutout.py` 抠图，压缩到每张 150KB 以内。表情要和第一张是同一个人。
