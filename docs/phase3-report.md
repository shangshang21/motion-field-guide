- 怀疑 1：成立；所有常驻动画合并一个调度器，离屏 / 后台暂停，磁吸、光源、墨迹和闲置演示收敛后休眠。

- 怀疑 3：部分成立；导览员硬阴影烘焙进 PNG，音量柱与自定义光标改 transform，首屏装饰离屏暂停；展柜内反色 / 遮罩保留以呈现原理。
- 怀疑 4：WebGL 原本已限制 DPR 1.5 / 离屏暂停；2D 粒子与 X-RAY 同样限至 1.5，四个 GPU 程序分展柜准备，消除整厅初始化长任务。
- 怀疑 5：监听原本 passive，但仍计算布局；现在只唤醒统一调度器，速度每帧计算一次。
- 怀疑 6：成立；七厅使用 content-visibility:auto，桌面 / 手机分厅固有尺寸，已渲染高度由浏览器记住；测量脚本随高度变化更新实际终点。
- 怀疑 7：补齐尺寸与 decoding=async，提前一屏 decode；拖尾与纹理提前解码。
- 怀疑 8：41 个音效原本按动作加载，未首屏全量解码；修复自动导览提前创建声音，改为首次交互后加载；素材与变体规则延续第二期。
- 怀疑 9：原本 font-display:swap；增加两种首屏字体预加载，全部新增中文重新生成思源黑体子集。
- 第 2 项：Nº24 改独立三幕路标时间轴，不再跨三排拉长；Nº26 增轮廓底稿，遮罩未揭开时也有内容。

最值得加的五件事（仅提议）：
1. 惯性拖拽与边界回弹：拖、甩、停、撞能让摩擦和重量成为可亲手比较的词汇。
2. 同屏 A/B 手感对比：同一展品保留两组参数一起播放，让“再弹一点”有明确参照。
3. 可拖动的动画时间轴：暂停、逐帧与慢放把蓄力、定格、回弹各阶段的差别直接摊开。
4. 口令分享链接与最小实现片段：让调好的手感能一键交给开发者并快速放进真实界面。
5. 减少动态效果对照：展示每个效果如何保留信息而降低运动，帮助把同一设计照顾到更多人。
